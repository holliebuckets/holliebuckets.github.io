### Deploying to GitHub Pages
To publish to your personal GitHub Pages:
1. Create a repository on [GitHub](https://github.com/new) (e.g. `portfolio-2026` or `<username>.github.io`).
2. Add the remote and push:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git add .
   git commit -m "Initial commit of external portfolio"
   git push -u origin main
   ```
3. Enable **GitHub Pages** under repository **Settings > Pages > Source: main branch**.
